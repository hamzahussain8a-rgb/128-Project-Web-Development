# Fitness Hub - Full-Stack Fitness Web Application

A full-stack fitness web application developed as part of the **CSIT128 Web Development** course at the **University of Wollongong in Dubai**. The application provides users with a centralized platform to explore workout plans, healthy meal recommendations, and fitness-related resources while demonstrating both frontend and backend web development concepts.

---

## Project Overview

Fitness Hub was designed to promote healthy lifestyles through an interactive web application. The project combines a responsive user interface with a custom Node.js backend that manages user interactions and application data.

The application demonstrates practical implementation of modern web development principles, including responsive design, client-server communication, user authentication, and data management.

---

## Features

- User Registration and Login
- Interactive Dashboard
- Workout & Exercise Library
- Healthy Meal Recommendations
- User Profile Management
- Comment & Feedback System
- Responsive Design for Desktop and Mobile
- JSON-based Data Storage
- Dynamic Content Rendering
- Custom Node.js HTTP Server

## Running the Project Locally

### Clone the repository

```bash
git clone https://github.com/hamzahussain8a-rgb/128-Project-Web-Development.git
```

### Navigate to the project

```bash
cd 128-Project-Web-Development
```

### Start the server

```bash
node server.js
```

### Open your browser

```
http://localhost:3000
```

> **Note:** Ensure Node.js is installed before running the application.
